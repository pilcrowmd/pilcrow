# PilcrowMD showcase files

Nine realistic example documents, written the way real people write them and, unlike the [test packs](../README.md), without any list of gaps.

- [pilcrow-showcase-ai-answer.md](pilcrow-showcase-ai-answer.md): a saved answer on planning a week of meals, with a table and a short script.
- [pilcrow-showcase-coders.md](pilcrow-showcase-coders.md): a project README with code in Kotlin and Python, a JSON config, a task list and links.
- [pilcrow-showcase-admins.md](pilcrow-showcase-admins.md): an incident note with a YAML snippet, a warning, a timeline and numbered steps.
- [pilcrow-showcase-product.md](pilcrow-showcase-product.md): a short product spec with a checklist, priorities and collapsible sections.
- [pilcrow-showcase-business.md](pilcrow-showcase-business.md): a quarterly summary with tables, figures and a quote.
- [pilcrow-showcase-legal.md](pilcrow-showcase-legal.md): contract clauses with nested lists, defined terms and footnotes.
- [pilcrow-showcase-science.md](pilcrow-showcase-science.md): a chemistry lab note with reaction formulas and a results table.
- [pilcrow-showcase-maths.md](pilcrow-showcase-maths.md): lecture notes with formulas, matrices and a theorem.
- [pilcrow-showcase-writers.md](pilcrow-showcase-writers.md): a short story in five chapters, with footnotes, emphasis and quotes.

All files are CC0 (public domain), like the rest of the test packs: see [the licence](../README.md#licence).
