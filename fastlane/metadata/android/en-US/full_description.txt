PilcrowMD is a beautiful, distraction-free Markdown reader and editor for Android. Open a .md file and see it as a clean page: serif type, a calm dark theme and plenty of space, so long documents are easy to read on a phone.

It is made for the Markdown you meet every day: answers from AI assistants, README files, technical docs, notes and specs. Save an AI chat answer as Markdown and PilcrowMD shows the headings, lists, tables, code and math cleanly, not as raw symbols.

WHY PILCROWMD

- Beautiful reading first. Premium serif type, a calm dark theme, a warm cream light theme, and a layout made for reading, not a cramped code editor.
- Free, no ads, no account, no tracking. No analytics, no crash reports. Fully open source (GPL-3.0).
- Never loses your work. Saving writes back exactly what you wrote. No silent reformatting, no half-written files.
- Read and edit. Switch between the clean reading view and a real source editor with syntax highlighting, line numbers, and undo/redo.
- Export to PDF. Save any document as a clean, print-ready PDF. Code blocks print on a light panel, in colour.
- Fast and offline. Native Android, no browser engine, works with no connection. (Optional online rendering for Mermaid diagrams is off by default.)

EVERYTHING MARKDOWN

- CommonMark + GitHub Flavored Markdown
- Tables, task lists, strikethrough, and links
- Syntax-highlighted code blocks
- LaTeX math ($$…$$)
- Pictures stored next to your note show inside the document. Web pictures are never downloaded
- YAML front matter
- Callout boxes (note, tip, warning) and collapsible sections
- Wide tables and code scroll sideways without breaking the page

READER TOOLS

- Search inside the document, with highlighted matches and next/previous
- Table of contents built from your headings. Tap to jump to any heading
- Links inside a document take you to the right heading, including Chinese and other non-Latin headings
- Buttons to jump to the top or bottom appear while you scroll
- Remembers where you stopped reading, per file
- Open .md files straight from your file manager or an email attachment
- Adjustable text size and a choice of reading fonts

MADE FOR

- Reading and saving answers from AI assistants and large language models
- README files and project docs on the go
- Technical specs, notes and meeting docs
- Anyone who works with .md or .markdown files

PilcrowMD opens .md, .markdown and .txt files. No sign-up, no ads. Just the cleanest way to read and edit Markdown on Android.
