Ruby TextMate grammar

Shipped as app/src/main/assets/textmate/ruby/ruby.tmLanguage.json, with one change.
Taken from microsoft/vscode at commit 21232ac569543d667ff07ccd2410ad880d7022c5,
file extensions/ruby/syntaxes/ruby.tmLanguage.json.
That file was converted by the VS Code project from Shopify/ruby-lsp
at commit e044408a069f43c892143f19c389628eebffbd01.
Changed (2026-10-01): in the block-parameter rule (top-level patterns[106]), the
look-behind alternatives "{\s+" and "do\s+" are spelled out for one to four
whitespace characters, because the app's regex engine (joni) accepts only
fixed-length look-behind alternatives. Nothing else is changed.
