TypeScript TextMate grammar

Shipped as app/src/main/assets/textmate/typescript/TypeScript.tmLanguage.json, with one change.
Taken from microsoft/vscode at commit 21232ac569543d667ff07ccd2410ad880d7022c5,
file extensions/typescript-basics/syntaxes/TypeScript.tmLanguage.json.
That file was converted by the VS Code project from microsoft/TypeScript-TmLanguage
at commit 48f608692aa6d6ad7bd65b478187906c798234a8.
Changed (2026-10-01): in the end pattern of the "using" declaration rule
(repository var-expr, patterns[2]), the look-behind alternatives
"^await\s+using" and "[^\._$[:alnum:]]await\s+using" are removed, because the
app's regex engine (joni) accepts only fixed-length look-behind alternatives.
"[^\._$[:alnum:]]using" already matches wherever they did. Nothing else is changed.
