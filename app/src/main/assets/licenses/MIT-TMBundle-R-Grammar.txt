R TextMate grammar

Shipped as app/src/main/assets/textmate/r/r.tmLanguage.json, unmodified.
Taken from microsoft/vscode at commit 21232ac569543d667ff07ccd2410ad880d7022c5,
file extensions/r/syntaxes/r.tmLanguage.json.
That file was converted by the VS Code project from REditorSupport/vscode-R-syntax
at commit b199996070723eefbe7a61e0384b2ae4768eb7f0.
That grammar continues REditorSupport/vscode-R (syntax/r.json at commit
b0781feedfadbcc35f40db5ce09cc9956d78547c), which was converted from
randy3k/R-Extended, published identically in randy3k/R-Box at commit
dfff2aad7ddc12062ee4b75cf5f8c2e3c3c6e566, and which incorporates rules from
textmate/r.tmbundle.
All five licences follow.
