JSON with Comments TextMate grammar

Shipped as app/src/main/assets/textmate/jsonc/JSONC.tmLanguage.json, unmodified.
Taken from microsoft/vscode at commit 21232ac569543d667ff07ccd2410ad880d7022c5,
file extensions/json/syntaxes/JSONC.tmLanguage.json.
That file was converted by the VS Code project from microsoft/vscode-JSON.tmLanguage
at commit 9bd83f1c252b375e957203f21793316203f61f70.
microsoft/vscode-JSON.tmLanguage re-publishes the JSON grammar of
Benvie/JavaScriptNext.tmLanguage under the MIT licence it was published under.
That grammar builds on textmate/json.tmbundle (Syntaxes/JSON.tmLanguage, unchanged
since commit 3f735aa84d6fb76a4a0d40a390a2e4d1685562ff; README at commit
5f974b9c388dac504ee372163a28ca1b86a22a1f).
All three licences follow.
