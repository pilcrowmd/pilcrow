Lua TextMate grammar

Shipped as app/src/main/assets/textmate/lua/lua.tmLanguage.json, unmodified.
Taken from microsoft/vscode at commit 21232ac569543d667ff07ccd2410ad880d7022c5,
file extensions/lua/syntaxes/lua.tmLanguage.json.
That file was converted by the VS Code project from sumneko/lua.tmbundle
at commit b295d83bf0e91b5d3a69eb097f9ed351623b95be.
sumneko/lua.tmbundle is a continuation of textmate/lua.tmbundle, whose history
it contains up to commit 8ae5641365b28f697121ba1133890e8d81f5b00e.
